>> Овчинников Олег Иванович (МБС-601-О-01/2)

>> Четвертую сдал

>> Вариант 5 лабы - 6 (Картография и Биомы)

> Добавьте в структуру карты тип биома (enum: Редколесье, Топь, Каменные руины, Кристальная пещера), который случайно выбирается при генерации каждого этажа и меняет процент препятствий и множитель золота (в Топи шаг стоит 2 стамины, в Кристальной пещере — тройное золото). Раз за этаж по кнопке M (за 5 стамины) герой может «зарисовать этаж», чтобы по возвращении домой продать карты в меню за бонусное золото. 


>> Вариант 4 лабы - 5 (Лес-кольцо)

>Если герой уходит за правый край карты, он мгновенно телепортируется на левый край этой же карты (без регенерации массива, только математика координат по модулю). Аналогично для верха и низа. Переход на новую карту осуществляется наступанием на портал (P). Портал появляется в случайном пустом месте на карте только когда герой “заблудится” совершит не менее 3 переходов через края экрана.
